# 真实十轮融合与单轮候选校正

2026-11-20。在[无循环双读出](option_trie_dual_readout.md)上做两类对照：推理时真的执行十轮，或者仅训练时用真实十轮的输出。所有正式准确率均为同一完整 GSM-MC test 1,319 题。训练池按种子 721 抽 1,536 题，排除教师微调用过的 1,024 题及旧双读出的 512 道校准题。前 1,024 题拟合，后 512 题用于校准路由阈值或选训练轮次，均未用正式测试集选权重。

## 推理时执行十轮

原双读出提供四个分数。慢分支使用原教师提示与 24 个 latent 槽，执行真实十轮共享块，输出 A/B/C/D logits；直接与快速分数相加，慢分支权重从训练池固定为 1。等权对照保留相同提示和权重，把循环分支替换为原生单轮。路由只观察快速分支的得分间隔和分支分歧，通过岭回归预测是否值得调用慢分支；校准阈值按预算选分位数，测试触发率会漂移。

| 方案 | 正式测试准确率 | P50 / P95 | 实测十轮调用率 |
| --- | ---: | ---: | ---: |
| 原生单轮，字母读出 | 43.44%（573/1319） | 12.38 / 15.14 ms | 0% |
| 十轮教师，字母读出 | 49.20%（649/1319） | 48.11 / 59.27 ms | 100% |
| 无循环双读出 | 49.96%（659/1319） | 14.59 / 16.44 ms | 0% |
| 双读出 + 同权重单轮字母分支 | 49.28%（650/1319） | 26.60 / 31.09 ms | 0% |
| 双读出 + 真实十轮 | 51.48%（679/1319） | 62.94 / 76.00 ms | 100% |
| 路由，训练校准预算 2.5% | 50.19%（662/1319） | 14.80 / 18.51 ms | 3.41% |
| 路由，训练校准预算 5% | 50.34%（664/1319） | 14.81 / 61.87 ms | 7.05% |
| 路由，训练校准预算 10% | 50.04%（660/1319） | 14.81 / 67.59 ms | 11.52% |
| 路由，训练校准预算 20% | 50.42%（665/1319） | 14.91 / 71.88 ms | 23.65% |

真实十轮分支比等权单轮分支高 2.20 pp，且比无循环双读出高 1.52 pp，说明十轮输出提供了互补的选项证据。但这组路由没有找到低成本、可保留大部分收益的工作点：低触发率收益小，高触发率则推高 P95。

## 训练时使用十轮残差

冻结原双读出，从每个数值候选结束符之前取出隐藏状态，并与字母分支的读出状态及两组分数融合。对每个候选用同一个约 12.6K 参数的 MLP 计算加性校正。比较纯答案 CE 和答案 CE 加 `0.5 * SmoothL1`；额外目标是同一标准提示下真实十轮与原生单轮 logits 的差，沿四选项去均值。两组推理都只有一次骨干前向，不调用教师。

| 方案 | 正式测试准确率 | P50 / P95 |
| --- | ---: | ---: |
| 无循环双读出，同卡复测 | 49.96%（659/1319） | 14.47 / 16.40 ms |
| 候选校正，仅答案监督，保存后复测 | 52.99%（699/1319） | 14.55 / 16.48 ms |
| 候选校正，答案 + 十轮残差监督 | 52.92%（698/1319） | 14.76 / 16.60 ms |

仅答案监督的候选头比无头版高 3.03 pp，同卡 P50 加约 0.08 ms，准确率高于十轮教师 3.79 pp。当前结果没有显示额外的十轮残差监督带来收益。这不是开放式生成的结果，也不宣称小幅差距显著。

均用 RTX 3090、BF16、batch 1、CUDA Graph 热态。级联用 GPU 0，等权单轮对照与候选头相关结果用 GPU 2。延迟含模型输入复制和结果读取，级联含路由同步和实际第二次推理，不含分词、提示打包、加载及构图。

## 小读出头输入消融

2026-11-21。同一 GPU 2、同一骨干和投影、同一训练/验证划分。从同样的初始化重训每个组，监督都是正确选项的交叉熵。禁用的特征列在训练和推理时置零，所有小头维持 `195 → 64 → 1`（12,609 参数）。所有组都保留双读出基础分数 `数值分 + 0.75 * 字母分`；去掉分数表示小头看不到标量特征，去掉字母状态也不等于去掉字母打分分支。

| 小头输入 | 正式测试准确率（全 1,319 题） | P50 / P95 |
| --- | ---: | ---: |
| 不加小头 | 49.96%（659/1319） | 14.56 / 16.39 ms |
| 全部 | 52.99%（699/1319） | 14.74 / 16.50 ms |
| 仅分数 | 49.20%（649/1319） | 14.75 / 16.60 ms |
| 分数 + 候选末端状态 | 52.24%（689/1319） | 14.75 / 16.60 ms |
| 分数 + 相对候选状态 | 50.95%（672/1319） | 14.76 / 16.61 ms |
| 分数 + 字母分支状态 | 49.73%（656/1319） | 14.76 / 16.61 ms |
| 全部去掉相对候选状态 | 53.07%（700/1319） | 14.85 / 16.70 ms |
| 全部去掉候选末端状态 | 51.55%（680/1319） | 14.85 / 16.70 ms |
| 全部去掉字母分支状态 | 53.30%（703/1319） | 14.86 / 16.71 ms |
| 全部去掉分数 | 49.28%（650/1319） | 14.86 / 16.72 ms |

候选末端状态是单独加到分数上最有效的一组；同时，小头必须看得到分数才能维持本次完整组合的收益。相对状态和字母状态各自去掉一项均未观察到准确率下降，不代表两者可以同时删掉而达到同样的准确率。无字母状态组是单种子在这批消融里的最高点，不宣称比完整版显著更好。遮罩控制保留了特征提取和原尺寸线性层，表中延迟不是物理裁剪后的速度。
