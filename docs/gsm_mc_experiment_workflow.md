# GSM-MC：十轮教师、蒸馏与双读出

## 统一数据口径

主入口：[scripts/2.sh](../scripts/2.sh)。从 `data/gsm-mc/train.jsonl` 按原教师的抽样种子 `42` 固定取 1,024 道题，写到 `outputs/jev-repro/train-1024.jsonl`（下称 A）。教师、所有学生、两跳中间模型、双读出融合校准、小头训练和小头消融都使用 **同一份 A**。两跳和单跳不另抽题；小头用全部 A 固定训练 12 个 epoch，不用额外验证集选择轮次。

脚本检查 A 的唯一性、与 test 的隔离，以及复用教师的训练数据哈希。旧教师可用原训练池的哈希、抽样种子和样本数核对。融合报告记录 A 的 SHA256，小头加载时校验融合报告和训练样本一致。训练题目数统一不意味着训练算力相同：渐进蒸馏比直接蒸馏多训练一个两跳模型。

正式评估只用 `data/gsm-mc/test.jsonl` 的全部 **1,319 道题**，只比较总准确率及 P50/P95 延迟。新流程默认在同一张卡上测 BF16、batch 1、热态 CUDA Graph；计入输入复制和读取预测，不计入分词、前缀树打包、模型加载与构图。

## 实验步骤

| 阶段 | 做法 | 主产物（相对 `outputs/jev-repro/`） |
| --- | --- | --- |
| 十轮教师 | 从 `Qwen/Qwen3-1.7B` 开始；共享 0-based `[9,18)` 九层，循环 10 次，阻尼 0.1，24 个 latent 槽。用真值答案 CE 和末轮全词表 KL（权重 1，温度 2）；KL 来源是看过训练题完整解题过程的原版 Qwen。双卡每卡 batch 4，累积 2，3 epoch，学习率 `2e-6`，训练随机种子 `43`。 | `teacher/experiment.json` 和模型权重 |
| 直接与捷径蒸馏 | 冻结十轮骨干，只训练共享块的 rank 16 低秩参数。比较答案 CE、加末轮 KL 与 `H10` 状态监督、再加 `H0→H5` / `H5→H10` 分段监督，以及加一次直跳与两次短跳的状态一致性。推理合并直跳权重，九层只走一次；另测两跳对照。 | `shortcut/test.json` 和各组 `.pt` |
| 渐进蒸馏 | 先让两跳模型从自己预估的 `H5` 出发走第二跳，末轮损失穿过两跳反传；再合并、冻结两跳模型，用其末态与 logits 教单跳。对照单跳 CE 与直接十轮蒸馏。两组单跳训练结构、初始化与步数相同。 | `progressive/test.json` 和各组 `.pt` |
| 无循环双读出 | 直接用原教师权重，无循环、无 latent 槽。字母分支打 A/B/C/D 分；数值分支把已知候选打包进前缀树，一次前向算出每个候选的 token 对数似然（包含换行），不逐 token 生成。数值分加经 A 校准的 `mix * 字母分`。 | `dual-readout/test.json` |
| 候选小头 | 冻结骨干，训练共享的 `195→64→1` 打分修正头。输入含候选末端状态、相对候选状态、字母读出状态与两路分数。不改原双读出。比较只用答案 CE 与加十轮/单轮字母 logits 残差监督，并对输入做消融。 | `candidate-head/test.json`、`test-confirmed.json`、`test-feature-ablation.json`、两个小头 `.pt` |

## 运行

在项目环境已装好 `uv` 依赖、数据文件就位后，从仓库根目录执行。训练默认用 GPU `0,2`，评估用 GPU `0`，Hugging Face 下载走 `https://hf-mirror.com`。预留至少 8 GiB 保存新教师权重；两卡全量训练时原实验峰值每卡约 23.1 GiB reserved。也可逐段运行脚本中的命令。

```bash
bash scripts/2.sh
```

复用本机历史教师（只跳过教师训练，仍按统一样本重新蒸馏、校准和训练小头）：

```bash
LOOP_TEACHER_MODEL="/var/tmp/loop-jev-$(id -u)/ce-kl-1024-block10-seed43-step0.1" \
  bash scripts/2.sh
```

用 `RUN_ROOT` 隔离不同运行；用 `TRAIN_GPUS`、`EVAL_GPU` 指定设备。脚本末尾注释中的旧入口不在默认流程内，旧脚本使用原来的固定产物目录。

## 历史结果

以下是旧报告的归档，不代表新脚本的复跑结果；除前两行和原 A 捷径组外，数据或评估口径按表区分。

| 历史方案 | GSM-MC test 准确率 | 单题 P50 / P95 | 训练或校准口径 |
| --- | ---: | ---: | --- |
| 原生单轮，原教师权重 | 43.44%（573/1319） | 12.23 / 14.91 ms | A，与下一行同次评估 |
| 原十轮教师 | 49.20%（649/1319） | 47.93 / 58.88 ms | A |
| 旧状态差分 / 绝对末态蒸馏 | 46.17%（609/1319） / 45.72%（603/1319） | 未在这次批量评估中测量 | A；真值 CE + 末轮 KL + 块出口状态 |
| 分段或捷径一致性，单跳 | 46.85%（618/1319） | 12.41 / 15.14 ms（分段） | A；路径一致性未提高准确率 |
| 直接蒸馏，单跳 | 46.78%（617/1319） | 12.35 / 15.13 ms | 教师用 A，学生用不重叠的 B（seed 927） |
| 两跳教师 | 47.38%（625/1319） | 16.30 / 19.97 ms | 教师用 A，两跳用 B |
| 十轮经两跳蒸馏成单跳 | 48.14%（635/1319） | 12.35 / 15.12 ms | 教师用 A，两跳和单跳都用 B；整链 2,048 道不同题 |
| 双读出，无候选头 | 49.96%（659/1319） | 14.47 / 16.40 ms | 与下行同次复测；另用 512 道题校准至 `mix=0.75` |
| 双读出 + 纯答案候选头 | 52.99%（699/1319） | 14.55 / 16.48 ms | 除教师和融合样本外，另用 1,024 道训练题和 512 道验证题 |
| 双读出 + 十轮残差候选头 | 52.92%（698/1319） | 14.76 / 16.60 ms | 同历史纯答案头的数据划分，残差未带来收益 |
| 小头消融：去掉字母状态 | 53.30%（703/1319） | 14.86 / 16.71 ms | 同历史小头数据；仍保留字母分数，置零消融不代表部署裁剪 |

双读出和蒸馏是独立分支：双读出不是从渐进单跳接着训练，而是直接继承原十轮教师权重。双读出只证明给定候选的 GSM-MC 表现，不代表开放式生成。历史报告详见[蒸馏记录](old/latent_loop_teacher_distillation_plan_2026-11-17.md)、[双读出](old/option_trie_dual_readout.md)和[小头及消融](old/option_loop_cascade_experiment.md)。

## 同数据流程验证

复用已核对数据的原十轮教师，使用 A 校准得到 `mix=3.0`，随后用同一份 A 训练两种小头。RTX 3090 同卡热态结果如下。这里只验证双读出和小头训练分支，未重训教师，也未重跑同数据的捷径、渐进蒸馏或输入消融。

| 同数据方案 | GSM-MC test 准确率 | 单题 P50 / P95 |
| --- | ---: | ---: |
| 双读出，无候选头 | 47.54%（627/1319） | 14.27 / 16.10 ms |
| 双读出 + 纯答案候选头 | 47.23%（623/1319） | 14.63 / 16.47 ms |
| 双读出 + 十轮残差候选头 | 48.45%（639/1319） | 14.65 / 16.49 ms |

验证产物在 `outputs/jev-repro-validation/`。此次不仅换了训练题口径，也重新校准了融合系数并固定训练轮次，不能把相对历史结果的变化单独归因于题目重叠。
